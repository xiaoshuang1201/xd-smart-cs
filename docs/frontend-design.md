# 新鼎电炉科技——智能客服系统 前端页面设计

## 一、设计概述

### 1.1 前端项目划分

| 项目   | 技术栈                                                | 用户群体     | 部署路径                |
| ---- | -------------------------------------------------- | -------- | ------------------- |
| 官网前端 | Nuxt 3 (Vue 3 + TypeScript + Pinia + Tailwind CSS) | 访客（潜在客户） | `xinding.com`       |
| 管理后台 | Vue 3 + Ant Design Vue 4 + TypeScript + Pinia      | 管理员/客服   | `xinding.com/admin` |
|      |                                                    |          |                     |

### 1.2 市面竞品参考

| 参考产品         | 参考点                  |
| ------------ | -------------------- |
| **Intercom** | 悬浮气泡动画、消息输入框设计、多会话切换 |
| **Zendesk**  | 知识库搜索嵌入、工单状态流转       |
| **美洽**       | 国内制造业客服UI、产品卡片消息     |
| **智齿科技**     | 机器人→人工切换动画、满意度收集     |

### 1.3 设计原则

1. **企业专业感**：以新鼎电炉品牌色（工业蓝+科技灰）为主色调
2. **渐进式交互**：从图标→气泡→聊天窗口→全屏页面，逐层深入
3. **加载感知**：每个异步操作有明确的loading/进度/完成状态
4. **移动端适配**：所有页面响应式设计，移动端优先

### 2.3 交互状态机

```
初始状态: 仅显示触发按钮（右下角蓝色圆形图标）
    │
    ├─ [访客点击触发按钮]
    │  → 展开聊天窗口（从右下角滑出动画，300ms ease-out）
    │  → 如果是首次打开：显示欢迎消息+建议问题
    │  → 如果已有历史会话：加载历史消息
    │
    ├─ [访客点击最小化]
    │  → 收回聊天窗口（滑入动画），保留触发按钮
    │  → 有新消息时：触发按钮显示红点Badge
    │
    ├─ [访客点击关闭]
    │  → 关闭窗口，触发按钮保留
    │  → 关闭当前会话（调用POST /close）
    │
    ├─ [访客点击"全屏对话"]
    │  → 跳转至 /chat 独立页面（携带 session_token）
    │
    └─ [跨页面导航]
       → 窗口保持展开/收起状态（Pinia store持久化）
       → 对话历史通过 session_token 恢复
```

### 2.4 关键交互细节

**流式输出动画**：
- AI头像旁显示"思考中..."带跳动圆点
- 逐字渲染，打字机效果（每字符约30ms延迟）
- 自动滚动到底部（如果用户未手动上滑）

**引用来源展示**：
- 消息下方以标签形式展示：`📎 IGBT产品手册V2.0 第12页`
- 点击标签弹出Popover显示原文片段

**转人工确认**：
- 当SSE推送 `event: need_transfer` 时
- 聊天区底部展示卡片："是否转接人工客服？"
- 用户点击"确认转接"后展示联系方式输入框

**移动端适配**：
- 移动端触发按钮缩小为48×48px
- 聊天窗口全屏展示
- 输入框底部固定，考虑键盘弹起

**断线重连**：
- SSE连接断开时，显示"连接已断开，正在重连..."
- 自动重连（指数退避：1s→2s→4s→8s→max 30s）
- 支持从断点续传（重连时携带最后收到的messageId）

### 3.3 与悬浮窗口的关系

- 悬浮窗口和独立聊天页**共享同一个 session_token**
- 用户从悬浮窗口点击"全屏对话" → 携带 session_token 跳转到 `/chat?token=sess_xxx`
- 在 `/chat` 页面发的消息，回到其他页面后悬浮窗口同步显示
- 通过 Pinia Store + localStorage 持久化 session_token

## 四、官网前端——页面上下文感知

### 4.1 实现方案

```
Nuxt 3 路由中间件 → 提取页面元信息 → 注入 Chat Composable
                                           │
                                           ▼
                              useChat().setPageContext({
                                pageType: 'product_detail',
                                productId: 'igbt-001',
                                category: '中频炉',
                                pageTitle: 'IGBT中频炉-300KW'
                              })
                                           │
                                           ▼
                              创建会话时作为 sourceContext 发送到后端
                                           │
                                           ▼
                              后端传递给 Dify → 影响建议问题和检索优先级
```

### 4.2 各页面类型上下文映射

| 页面类型 | sourceContext | 建议问题示例 |
|----------|---------------|-------------|
| 首页 | `{pageType: "home"}` | 通用欢迎问题 |
| 产品列表 | `{pageType: "product_list", category: "中频炉"}` | 该类别下的参数对比 |
| 产品详情 | `{pageType: "product_detail", productId: "xxx"}` | 该产品的参数、价格、选型 |
| 案例页 | `{pageType: "case", caseId: "xxx"}` | 类似案例的咨询 |
| 联系页 | `{pageType: "contact"}` | 询价、合作咨询 |
| 售后支持 | `{pageType: "support"}` | 故障排查、维修咨询 |

## 九、性能优化要点

1. **SSE连接复用**：整个会话期间复用同一个SSE连接，避免频繁建立
2. **虚拟滚动**：对话消息列表超过200条时启用虚拟滚动（vue-virtual-scroller）
3. **Markdown懒渲染**：AI消息的Markdown内容按需渲染（Intersection Observer）
4. **图表按需加载**：ECharts组件使用动态import + `v-if` 懒加载
5. **代码分割**：管理后台按路由分割（Vite自动处理）
6. **Ant Design Vue 按需引入**：使用unplugin-vue-components自动导入
